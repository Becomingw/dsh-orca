截图直接加载本仓库的 `client.js`，通过独立的文档演示容器提供 React、主题变量与模拟宿主槽位，再使用浏览器渲染。额外页头和并排布局仅用于文档展示，不代表 DSH 的完整窗口布局。

所有接口均返回内存中的虚构数据，不读取 SSH 配置、DSH 配置、授权记录或远端主机。浏览器仅允许访问本地预览服务，截图过程未执行 SSH 或修改真实授权。

示例数据统一使用 `gpu-alpha`、`gpu-beta`、`cpu-worker` 与 `/srv/demo/`，任务、日志、GPU 型号和指标均为演示值。截图不包含个人姓名、账号、地址、真实主机、个人文件路径或实际任务内容，也不包含桌面、会话列表和浏览器地址栏。

更新截图时应继续使用独立示例数据渲染组件，避免通过遮罩或模糊处理实际工作区截图。
